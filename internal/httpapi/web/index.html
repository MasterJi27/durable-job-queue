Built to recover.

Durable is a PostgreSQL-backed job queue written in Go. This console reads from the same API your producers and workers use.

  1. Submit once. Retry safely.Idempotency keys deduplicate requests within a queue.
  2. Lease the work.Workers renew expiring leases. Fencing versions reject old workers after reassignment.
  3. Commit the result.The result and acknowledgement share a database transaction.
  4. Keep every outcome visible.Failures retry with backoff, then remain as dead-letter jobs when the budget is exhausted.

Processing attempts can repeat. Exactly-once completion applies to committed database results and business writes inside the completion transaction, not arbitrary external side effects.
